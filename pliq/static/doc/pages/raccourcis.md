# Raccourcis clavier

## Dans le Flow

Le plan doit avoir le focus : cliquez le fond une fois.

| Touche | Effet |
|---|---|
| `+` `=` | zoomer |
| `−` | dézoomer |
| `0` | revenir à 100 % |
| `F` | ajuster : tout faire tenir à l'écran |
| flèches | déplacer le plan |
| ⇧ + flèches | le déplacer de trois crans |
| ⌘/Ctrl + molette | zoomer là où est le curseur |

Dans le champ **chercher un dataset** : `Entrée` centre le plan sur le premier
résultat, `Échap` vide le champ.

## Dans une recipe

| Touche | Effet |
|---|---|
| ⌘Z / Ctrl+Z | annuler |
| ⇧⌘Z / Ctrl+Y | rétablir |

Dans un champ de saisie, ⌘Z appartient au champ : c'est le texte en cours qu'on
annule, pas l'étape. L'historique vit dans l'onglet et meurt avec lui — voir
[L'écran d'une recipe](recipe-ecran.md#annuler-retablir).

## Partout

| Touche | Effet |
|---|---|
| `Échap` | ferme la modale du dessus, et lui rend le focus qui l'avait ouverte |
| `Tab` | circule dans la modale ouverte, sans en sortir |

## Dans cette documentation

| Touche | Effet |
|---|---|
| `/` | aller à la recherche |
| `Entrée` | ouvrir le premier résultat |
| `Échap` | vider la recherche et la fermer |
