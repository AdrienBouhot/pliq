# Se déplacer dans le flux

Le Flow est un plan qu'on déplace, pas une page qu'on fait défiler.

## Les gestes

| Geste | Effet |
|---|---|
| Glisser le fond | déplacer le plan |
| Molette / deux doigts | déplacer le plan |
| ⌘/Ctrl + molette, pincement | zoomer là où est le curseur |
| `+` `−` `0` `F`, flèches | zoomer, revenir à 100 %, ajuster, déplacer |
| **Ajuster** | tout faire tenir à l'écran |

Les touches n'agissent que lorsque le plan a le focus : cliquez le fond une
fois, puis `F` ajuste, `0` revient à 100 %, les flèches déplacent (et
`⇧ + flèche` déplace de trois crans). La liste complète est dans
[Raccourcis clavier](raccourcis.md).

## Le cadrage se refait tout seul, jusqu'au premier geste

Tant que vous n'avez rien déplacé, le cadrage se refait tout seul : ouvrir un
projet, replier une zone ou redimensionner la fenêtre recadre le flux.

Au premier geste, c'est **votre** cadrage qui prime — l'atelier cesse de
recadrer sous vos doigts. **Ajuster** rend la main.

## Sous 55 %, les libellés s'effacent

En dessous de 55 %, les noms des nœuds disparaissent : à cette taille ils ne
forment qu'une bouillie grise. Les formes, les couleurs et le nom des zones
restent — c'est encore la carte du projet, ce n'est simplement plus une liste
de noms.

> [!astuce] Pour retrouver une table dans un grand projet, le champ **chercher un dataset** est plus rapide que le zoom : `Entrée` centre le plan sur le premier résultat. Voir [Quand il y a trop de tables](flow-grands-projets.md#chercher).
